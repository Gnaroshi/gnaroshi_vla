# LR-NODE Method Files

This directory contains non-invasive reference copies of LR-NODE method-owned
files from the current Seer source:

- `lrnode_modules.py` copied from `architectures/seer/upstream/models/lrnode_modules.py`
- `lrnode_logging_utils.py` copied from `architectures/seer/upstream/utils/lrnode_logging_utils.py`

The upstream copy still uses its original import paths. These files are here to
make the method ownership explicit and to provide a target for a future behavior
preserving refactor.
