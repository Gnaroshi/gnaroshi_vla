# Archived Seer experiment entrypoints

This directory contains completed, rejected, or superseded Seer experiment
entrypoints retained only for source provenance. They are not supported launch
commands and may reference deleted intermediate checkpoints or result roots.

Use the active entrypoints listed in the parent `README.md`. Final outcomes from
these experiments are recorded in `codex_outputs/seer/legacy_results.md` and the
pre-cleanup source hashes are recorded in
`codex_outputs/seer/pre_cleanup_code_inventory.tsv`.
